Como instalar

Três passos e pronto

  1. 1

    Baixe o instalador

    Escolha uma das opções:

    • Instalador NSIS — clinica-psi_1.0.0_x64-setup.exe (~2,5 MB), instala para o seu usuário sem pedir senha de administrador.
    • Versão portátil — clinica-psi.exe, funciona direto, basta executar (pode ser necessário permitir o Windows proteger o PC na primeira abertura).
  2. 2

    Abra e siga o assistente

    A instalação é só para o seu usuário do Windows — não pede senha de administrador.

  3. 3

    Entre no sistema

    O app já vem com uma clínica de demonstração para você explorar sem cadastrar nada.

“O Windows protegeu o seu PC”?

É esperado nesta versão de teste: o instalador ainda não tem assinatura digital. Clique em Mais informações e depois em Executar assim mesmo. O arquivo é o mesmo publicado no repositório do projeto — o código-fonte está aberto para conferência.
