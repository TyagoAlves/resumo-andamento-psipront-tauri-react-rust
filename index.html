Recursos

O que já está funcionando

Tudo abaixo foi implementado e faz parte da versão que está sendo avaliada.

Agenda do dia

Sessões com horário, duração e profissional. Avisa conflitos, guarda notas e imprime a agenda em PDF.

Prontuário por paciente

Evoluções, dados de contato e histórico completo em uma ficha única, com acesso rápido pela agenda.

Termos LGPD

Consentimento com vigência, modelo de termo editável e exportação dos dados de cada profissional.

Relatórios

Produção por período e termo assinado, prontos para imprimir ou salvar em PDF.

Senha protegida

A senha nunca é gravada em texto puro: o sistema guarda apenas o hash (PBKDF2, via WebCrypto).

Permissões por perfil

Quem administra vê a clínica inteira. Cada profissional vê os próprios pacientes e os sem responsável.

Backup e restauração

Cópia automática do banco com retenção, além de exportar e restaurar backup manual — exigindo a senha atual.

Configurações compartilháveis

Exporta e importa identidade, marca, textos e modelos de termo — sem nenhum dado de paciente.

Quem já usava a versão antiga não perde nada: na primeira abertura, os dados da POC (equipe, pacientes, serviços, agenda, evoluções e termos) são migrados automaticamente.

Tecnologia

Como o app foi construído

O mesmo código de interface roda no aplicativo e na versão web. A diferença fica só na camada de armazenamento — o domínio não sabe onde os dados moram.

Interface React 19 · TypeScript · Vite · Tailwind telas, componentes e estado da sessão
↓
Regras e dados Serviços · repositórios · StorageAdapter contrato único de chave-valor, independente do alvo
↓
App desktop SQLite via Rust %APPDATA%\br.com.clinicapsi.prontuario
Versão web localStorage usada nos testes automatizados

Por que um app de desktop?

  • Sem teto de 5 MB: o navegador limita o localStorage; o SQLite não.
  • Dados no computador da clínica: nada é enviado para servidores de terceiros.
  • Backup consistente: o Rust faz a cópia do banco com o aplicativo aberto.
  • Instalação sem administrador: o instalador coloca o app só para o usuário.
